## 3. Fuzzy-weight results you can show

These examples were generated by the actual Mamdani system.

### Sample A: All experts agree and are confident

```text
EEG probability:   [0.91 Sad, 0.09 Happy]
Audio probability: [0.88 Sad, 0.12 Happy]
Video probability: [0.90 Sad, 0.10 Happy]

EEG confidence = 0.91
Audio confidence = 0.88
Video confidence = 0.90
Disagreement = 0.02

Fuzzy weights:
EEG   = 0.337
Audio = 0.330
Video = 0.334
```

Meaning: when all experts agree, they receive almost equal trust.

### Sample B: Audio is uncertain

```text
EEG probability:   [0.91 Sad, 0.09 Happy]
Audio probability: [0.54 Sad, 0.46 Happy]
Video probability: [0.88 Sad, 0.12 Happy]

EEG confidence = 0.91
Audio confidence = 0.54
Video confidence = 0.88
Disagreement = 0.247

Fuzzy weights:
EEG   = 0.435
Audio = 0.139
Video = 0.426
```

Meaning: uncertain audio is trusted much less. EEG and video receive more
weight.

### Sample C: EEG is uncertain

```text
EEG confidence = 0.52
Audio confidence = 0.90
Video confidence = 0.87
Disagreement = 0.253

Fuzzy weights:
EEG   = 0.132
Audio = 0.438
Video = 0.430
```

Meaning: the fuzzy system reduces EEG when EEG is weak.

### Sample D: Video is uncertain

```text
EEG confidence = 0.89
Audio confidence = 0.86
Video confidence = 0.53
Disagreement = 0.240

Fuzzy weights:
EEG   = 0.433
Audio = 0.425
Video = 0.142
```

Meaning: the fuzzy system reduces video when video is weak.

### Sample E: Audio conflicts with EEG and video

```text
EEG probability:   [0.91 Sad, 0.09 Happy]
Audio probability: [0.08 Sad, 0.92 Happy]
Video probability: [0.88 Sad, 0.12 Happy]

EEG confidence = 0.91
Audio confidence = 0.92
Video confidence = 0.88
Disagreement = 0.553

Fuzzy weights:
EEG   = 0.334
Audio = 0.336
Video = 0.329
```

Meaning: all three experts are confident, so the four-input fuzzy system
cannot safely decide which one is wrong. The weights stay almost equal. This
is an honest limitation, not a hidden failure.

### Sample F: All experts are equally uncertain

```text

Disagreement = 0.00

Fuzzy weights:

Audio = 0.333
Video = 0.333
```

Meaning: if everyone is equally uncertain, they share the decision equally.

## 4. What these results prove

The fuzzy layer is working as designed:

```text
Normal and confident experts
        -> almost equal weights

Poor / uncertain audio
        -> audio weight decreases

Poor / uncertain video
        -> video weight decreases

Poor / uncertain EEG
        -> EEG weight decreases

All experts the same
        -> equal weights
```

This is the main demonstration you can show without the EAV dataset.

## 6. How to show this work to your teacher

### Best 6-minute live demo

Open these files in this order:

1. `docs/COMPLETE_SYSTEM_SIMPLE_GUIDE.md`
2. `docs/FUZZY_FUSION_SIMPLE_GUIDE.md`
3. This file: `docs/RESULTS.md`
4. GitHub: [https://github.com/HAWKAARJAV/Soft-Computing](https://github.com/HAWKAARJAV/Soft-Computing)

Then speak in this order:

**Minute 1 — Problem**

> We detect Sad or Happy using EEG, audio, and video together. One modality
> can become noisy or uncertain, so the system should not always trust all
> three equally.

**Minute 2 — Original model**

> The original model has three neural experts. Each expert produces 128
> features. The old method joins them into 384 features and uses an MLP. We
> kept this model unchanged as the baseline.

**Minute 3 — What we added**

> We added a small classifier after each expert so EEG, audio, and video each
> produce their own Sad/Happy probability. From those probabilities we get
> three confidences and one disagreement value.

**Minute 4 — Fuzzy logic**

> These four numbers enter a Mamdani fuzzy system with 81 Low/Medium/High
> rules. Centroid defuzzification converts the fuzzy output into three
> reliability weights. The weights are normalized and used to combine the
> three probabilities.

**Minute 5 — Live proof**

Run this in the terminal:

```bash
export PYTHONPATH="."
python3 -m unittest tests/test_fuzzy_inference.py -v
```

Then show Sample B from this file:

```text
Audio confidence = 0.54
Audio weight     = 0.139
EEG weight       = 0.435
Video weight     = 0.426
```

Say:

> When audio is uncertain, the fuzzy system automatically reduces the audio
> weight. EEG and video get more influence.

**Minute 6 — Honest ending**

> We also compare fuzzy fusion with the original model, individual modalities,
> averaging, and fixed weights. The fuzzy math is complete and tested. Full
> dataset accuracy will be filled after evaluation on the EAV data. We do not
> claim fuzzy fusion is better until that experiment is run.

### If the teacher asks for code

Open these four files:

| File | Why it matters |
|---|---|
| `src/models/multimodal_model.py` | Original EEG, audio, video experts |
| `src/models/modality_heads.py` | Separate Sad/Happy heads |
| `src/fuzzy/fuzzy_rules.py` | 81 explainable rules |
| `src/fuzzy/fuzzy_inference.py` | Mamdani inference and centroid defuzzification |

### If the teacher asks a question

Use these short answers.

**What is Mamdani?**

> It is a fuzzy method that uses IF-THEN rules. First it converts numbers into
> Low/Medium/High. Then it applies rules. Then it combines the rule outputs.

**What is centroid defuzzification?**

> After the rules fire, the answer is still a fuzzy area. The centroid finds
> the balance point of that area and turns it into one exact weight.

**Why not put the 384-D vector into fuzzy logic?**

> Fuzzy rules need a few understandable inputs. Confidence and disagreement
> are easy to explain. A 384-number vector is not.

**Did fuzzy fusion improve accuracy?**

> The fuzzy system is working and changes weights correctly. Dataset accuracy
> is not reported yet because the evaluation data is not in this folder.
